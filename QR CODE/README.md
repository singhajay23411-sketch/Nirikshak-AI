# Nirikshak AI • Live Platform QR Code Suite
**Live Target URL:** `http://155.248.255.235`

---

## 🎯 Overview
This directory contains the instant-scan high-contrast QR code generation engine and assets pointing directly to the live **Nirikshak AI • MPLADS** platform: `http://155.248.255.235`.

When scanned with a phone, it directs the evaluator/visitor to a clean device-selection landing page where they can choose to:
1. **📱 Open on Phone** $\rightarrow$ Immediately launches `http://155.248.255.235` directly in their mobile browser.
2. **💻 Open on Laptop** $\rightarrow$ Displays the link `http://155.248.255.235` with an instant one-click copy button (**Copy Link** $\rightarrow$ **✓ Link Copied**).

## 💡 How to Add to Your Presentation Slide
1. Open your presentation slide in PowerPoint / Google Slides / Canva.
2. Insert picture: choose **`nirikshak_qr_card.png`** (or **`nirikshak_qr_code.png`**).
3. The QR code points to `http://155.248.255.235/demo`.
